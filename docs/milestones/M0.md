# M0. Каркас

## План

1. pnpm-монорепо: `apps/desktop` (electron-vite: main / preload / renderer).
2. Окно Electron с React-оболочкой: боковая панель проектов, пустой экран, строка статуса.
3. i18n ru (по умолчанию) / en, светлая и тёмная темы.
4. `pnpm check` = typecheck + Biome + vitest; Playwright smoke «приложение открылось».
5. tRPC поверх IPC и SQLite (drizzle + первая миграция).

## Итог (шаг 1: запускаемая основа)

Сделано: пункты 1–4. По просьбе «сначала основу, чтобы можно было запустить» пункт 5 вынесен в следующий шаг M0.

Проверить руками:
- `pnpm install` → `pnpm dev`: открывается окно Studio с пустым экраном.
- Переключить язык RU/EN и тему внизу боковой панели — интерфейс меняется сразу и запоминается после перезапуска.
- `pnpm check` — зелёный; `pnpm test:e2e` — smoke проходит.

Шаг 2 (tRPC поверх IPC, `packages/schema`, `packages/db` + первая миграция) сделан вместе с картой проекта — см. `M1.md`.
