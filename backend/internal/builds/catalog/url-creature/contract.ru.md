# Лаборатория существ

Сделай **лабораторию существ**: страницу с одним существом, которое собрано из шести чисел, мутирует по кнопке и
целиком живёт в своей ссылке. Отправь кому-нибудь ссылку, и он увидит ровно то существо, которое видишь ты. Кто это
(медуза, робот, цветок, крошечное божество) и как каждое число лепит существо, придумываешь ты; правила ниже
общие для всех лабораторий.

## Геном

- **Геном** существа это **шесть целых чисел, каждое от 0 до 7** включительно. Порядок важен. В виде текста это
  шесть чисел через точку: `3.1.4.1.5.2`.
- **Геном по умолчанию**: `0.0.0.0.0.0`.
- **Каждое число должно менять облик.** Замена любого одного из шести чисел на любое другое значение меняет
  внешний вид существа (какими бы ни были остальные пять), так что все 8 значений каждого числа дают 8 разных
  обликов. Как именно, решаешь ты: цвет, размер, форма, число глаз, узор, настроение.
- **Облик зависит от генома и ни от чего больше.** Один и тот же геном выглядит одинаково: после мутации, после
  `setGenome`, после перезагрузки, когда ссылку открыли в новой вкладке, через минуту. Никакого случайного
  декора, выбранного при отрисовке, и ничего, что зависит от истории прошлых мутаций.
- Всё, чем существа отличаются на вид, находится внутри элемента `data-testid="creature"` (см. ниже). Лёгкое
  движение на месте приветствуется (дыхание, моргание, дрейф), но только через CSS-анимации, CSS-переходы или Web
  Animations API: проверки останавливают их, прежде чем смотреть. Всё остальное внутри элемента существа (canvas,
  перерисовываемый по таймеру, движение из скрипта, случайные значения) не должно менять облик при данном геноме.

## Геном живёт в URL

Фрагмент URL это единственный источник правды о существе, как и нужно для ссылки, которой делятся.

- Корректный фрагмент это **ровно** `#g=` и шесть одиночных цифр `0`-`7` через одиночные точки:
  `#g=3.1.4.1.5.2`. Ничего до него во фрагменте и ничего после. Всё остальное **некорректно**: нет фрагмента или он
  пустой, `#g=`, буквы (`a.b.c.d.e.f`), числа вне 0-7 (`99`, `8`, `-1`), меньше или больше шести чисел, ведущий ноль
  (`03`), другие разделители (`,` или никаких), точка на конце, лишние параметры (`#g=1.2.3.4.5.6&x=1`), другой ключ
  (`#G=` или `#x=`). Никакого декодирования и починки: фрагмент либо в точности корректен, либо нет.
- При загрузке корректный фрагмент задаёт существо. **Некорректный или отсутствующий фрагмент даёт существо по
  умолчанию `0.0.0.0.0.0`**, страница продолжает работать и не пишет ошибок (ни необработанных исключений, ни
  `console.error`). Нигде не должно появиться `NaN`, `null` или `undefined`.
- **Адресная строка всегда показывает текущее существо.** Если существо не соответствует `location.hash`
  (страницу открыли без фрагмента или с некорректным), фрагмент переписывается в `#g=` + геном, так что после
  загрузки, после каждого `setGenome` и после каждой мутации `location.hash === "#g=" + геном` (например,
  `"#g=0.0.0.0.0.0"` на пустой странице). Меняется только фрагмент: путь и query-строка остаются как есть. Добавляется
  ли при этом запись в историю, решаешь ты.
- Поэтому перезагрузка возвращает то же существо. Не храни геном где-то ещё (storage, cookies) вместо фрагмента.
- **Страница следует за адресной строкой.** Если фрагмент меняется при открытой странице (пользователь правит URL,
  скрипт ставит `location.hash`, браузер идёт «назад»), существо, подпись генома, ссылка и API следуют за ним:
  корректный новый фрагмент показывает это существо, некорректный даёт существо по умолчанию, а адрес
  переписывается в `#g=0.0.0.0.0.0`. Перезагрузки страницы нет.

## API

```js
window.__creature = {
  getGenome() {},      // -> массив из 6 чисел, например [3, 1, 4, 1, 5, 2]
  setGenome(arr) {},   // -> true, если применено, false, если отклонено
}
```

Он есть к моменту события `load`, и `getGenome` верен с первого мгновения.

- `getGenome()` каждый раз возвращает **новый массив из шести JavaScript-чисел** (не строк). Изменение
  возвращённого массива не меняет существо.
- `setGenome(arr)` принимает только настоящий **массив ровно из шести значений, каждое из которых число, целое от 0
  до 7**. Тогда он применяет геном и возвращает `true`: существо, подпись генома и ссылка обновляются, а фрагмент
  становится `#g=` + геном. Установка того генома, что уже показан, допустима и возвращает `true`. Массив
  копируется: его последующее изменение ничего не меняет.
- На **всё остальное** `setGenome` возвращает **`false`**, не меняет вообще ничего (существо, подпись, ссылку, URL) и
  **не бросает исключение**. Сюда относится: не массив (строка `"1.2.3.4.5.6"`, `null`, `undefined`, объект, вызов без
  аргумента), неверная длина (5 или 7), значения, не являющиеся числами (`"3"`, `true`, `null`, `undefined`, дырка в
  разреженном массиве), числа вне 0-7 и нецелые числа (`1.5`, `NaN`, `Infinity`). Ничего не округляется, не
  обрезается и не приводится к числу.

## Элементы

Ищутся по `data-testid`; страница проверяется в окне размера десктопа.

| `data-testid` | Что это |
|---------------|---------|
| `creature` | само существо, видимое, не меньше 96 x 96 px. Всё, чем существа различаются, нарисовано внутри него (DOM, SVG, CSS или canvas) |
| `genome` | элемент, текст которого ровно геном в виде `a.b.c.d.e.f`, например `3.1.4.1.5.2` (пробелы по краям не считаются, больше ничего внутри). Всегда текущий геном |
| `mutate` | кнопка |
| `copy-link` | элемент (кнопка, поле ввода, что угодно), который **показывает готовую ссылку**: его текст, а для поля ввода его значение, содержит полный адрес страницы, ровно `location.href`, вместе с `#g=…`. Всегда актуален и продолжает показывать ссылку после клика. Клик должен копировать ссылку в буфер обмена; если буфер недоступен, это должно пройти тихо (без необработанных ошибок). Пометка «Скопировано!» рядом или внутри приветствуется |

Подпись генома и ссылка следуют за каждым изменением генома из любого источника: mutate, `setGenome`, адресная
строка, твои собственные элементы управления.

## Мутация

Нажатие `mutate` делает **мутацию** текущего существа:

- Новый геном **отличается от прежнего хотя бы в одном числе**: клик никогда не остаётся без эффекта, сколько бы раз
  подряд и с какого бы генома ни начинали, включая `7.7.7.7.7.7` и `0.0.0.0.0.0`.
- Каждое число результата это целое от 0 до 7, всегда.
- Мутации продолжают исследовать: двадцать подряд из любого генома проходят не меньше пяти разных геномов
  (залипшая кнопка или цикл между двумя существами это не мутация).
- Эффект **мгновенный**: к моменту, когда клик обработан, `getGenome()`, подпись, ссылка и фрагмент уже показывают
  новый геном, а кнопка сразу снова работает (анимируй существо сколько угодно, но не блокируй кнопку). Поскольку
  облик зависит от генома, мутация всегда меняет облик существа.
- Какие числа меняются, насколько, случайно или нет: решаешь ты. Небольшие сдвиги одного-двух чисел похожи на
  генетику, полная перетасовка на новое животное.
