# Markdown notes

Build a **Markdown notes app** as a static web page.

## Must have

- A list of notes; create, rename and delete a note.
- An editor with a live preview: headings, bold, italic, lists, links and code blocks.
- Notes are kept in the browser (`localStorage`) and survive a reload.
- Search over note titles and text.
- Works on a phone screen (375 px wide) without horizontal scrolling.

## Nice to have

- Export a note as a `.md` file.
- Dark mode.
- Task lists (`- [ ]`) you can tick in the preview.

## Rules

Static files only: an `index.html` at the root of the zip plus any CSS, JS and images. No server, no
external API keys. Use relative paths (`./app.js`, not `/app.js`). Up to 5 MB.

## Judging

No automatic scoring: after the deadline every site is shown to everyone and people vote. Up to 3
uploads; your latest counts.
