# Pomodoro timer

Build a **Pomodoro timer** as a static web page.

## Must have

- A 25-minute focus timer and a 5-minute break timer; every fourth break is 15 minutes.
- Start, pause and reset. The remaining time is visible in the page title too.
- A count of focus sessions finished today, kept across page reloads (`localStorage`).
- A sound or a visible signal when a timer ends.
- Works on a phone screen (375 px wide) without horizontal scrolling.

## Nice to have

- Custom durations.
- Keyboard shortcuts (space to start/pause).
- A design people want to keep open all day.

## Rules

Static files only: an `index.html` at the root of the zip plus any CSS, JS and images. No server, no
external API keys. Use relative paths (`./app.js`, not `/app.js`). Up to 5 MB.

## Judging

No automatic scoring: after the deadline every site is shown to everyone and people vote. Up to 3
uploads; your latest counts.
